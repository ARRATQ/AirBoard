# Se repérer dans le portail

Le portail réunit vos outils, les actualités, l'agenda et les échanges de l'organisation. Ce guide vous montre où trouver chaque chose.

## Le menu de gauche

- **Accueil** : votre page de départ.
- **Ressources**, **News Hub**, **Agenda**, **Sondages**, **Boîte à suggestions**, **My XP**, **Trombinoscope**, **Recherche** : une page par module.
- **Administration** : n'apparaît que si votre rôle vous donne des pages à gérer. Vous n'y voyez que celles-là.

Sur téléphone, le menu s'ouvre avec le bouton en haut de l'écran.

## La page d'accueil

Elle résume ce qui vous concerne aujourd'hui :

- **À la une** et le **Fil d'actualités** : les derniers articles ;
- **Événements à venir** ;
- **Sondages** en cours, avec un bouton **Voter** ;
- **Ressources favorites** et ressources **Récemment ajoutées** ;
- **Mon XP** : votre niveau et vos badges.

## Chercher

1. Cliquez dans la barre **Rechercher dans le portail**, en haut de l'accueil, ou appuyez sur **Ctrl K** (**⌘K** sur Mac).
2. Tapez au moins 2 caractères.
3. Filtrez si besoin : **Ressources**, **Actualités**, **Événements**, **Sondages**, **Annonces**.

## Régler l'affichage

En bas du menu :

- **Taille d'affichage** (« Auto · 100 % ») : agrandit ou réduit tout le portail ;
- **Mode sombre** : bascule entre clair et sombre ;
- **Langue** : français, anglais, espagnol ou arabe ;
- **Aide** (point d'interrogation) : ouvre ces guides, directement sur la page où vous êtes.

> **Bon à savoir** : votre nom, en bas du menu, ouvre **Mon Profil** et **Se déconnecter**.
