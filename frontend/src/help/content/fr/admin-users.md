# Utilisateurs

La page **Administration → Utilisateurs** crée et gère les comptes. Les personnes qui se connectent avec Microsoft ont leur compte créé à la première connexion.

## Créer un compte

1. Ouvrez [Utilisateurs](/admin/users) et cliquez sur **Nouvel utilisateur**.
2. Onglet **Compte** : **Nom d'utilisateur** (il ne change plus ensuite), **Adresse email**, prénom, nom et **Mot de passe**. Gardez **Compte actif** coché.
3. Onglet **Rôle & groupes** :
   - **Rôle** : **Utilisateur** (accès aux ressources de ses groupes) ou **Administrateur** (accès à tout) ;
   - **Groupes d'utilisateurs** : ils déterminent ce que la personne voit ;
   - **Rôles attribués** : les rôles créés dans la page Rôles (voir le guide « Rôles et permissions »).
4. Cliquez sur **Créer l'utilisateur**.

## Limiter un rôle à certains groupes

Dans **Rôles attribués**, chaque rôle propose **Groupes couverts par le rôle**. Sans choix, le rôle s'applique aux groupes dont la personne est membre (hors groupe par défaut). Choisissez des groupes pour le restreindre.

## Suspendre ou supprimer

- **Désactiver** : la personne ne peut plus se connecter ; **Activer** la rétablit.
- **Supprimer** place le compte dans la **Corbeille** : **Restaurer l'utilisateur** le récupère.
- Depuis la corbeille, **Supprimer définitivement** efface le compte et ses données. C'est irréversible.

> **Bon à savoir** : les groupes qui viennent du trombinoscope sont **verrouillés** dans la fiche. Ils suivent l'entité de la personne : changez son affectation dans le trombinoscope pour les modifier.
