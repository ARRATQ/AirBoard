# Trombinoscope

Le [Trombinoscope](/directory) présente l'organisation : ses unités, ses postes et les personnes qui les occupent.

## Trouver quelqu'un

1. Ouvrez **Trombinoscope** dans le menu.
2. Tapez un nom, un poste, une unité ou un e-mail dans la recherche, ou choisissez une unité dans **Toutes les unités**.
3. Cliquez sur une personne : sa fiche affiche ses **Coordonnées** et ses **Postes occupés**.

## Parcourir l'organisation

- **Tout déplier** / **Tout replier** : ouvre ou ferme toutes les unités.
- **Organigramme** : vue en arbre. **Afficher cette unité comme racine** recentre la vue sur une unité ; **Toute l'organisation** revient à l'ensemble.

> **Bon à savoir** : **Intérim** signale un poste tenu temporairement. **Poste vacant** : personne ne l'occupe pour l'instant.

> Une information vous concernant est fausse ? Signalez-la à l'administrateur : c'est lui qui tient le trombinoscope à jour.
