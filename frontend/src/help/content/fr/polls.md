# Sondages

Les [Sondages](/polls) recueillent votre avis. Vous ne voyez que ceux ouverts à tous ou à vos groupes.

## Voter

1. Ouvrez **Sondages** dans le menu, ou cliquez sur **Voter** depuis l'accueil.
2. Choisissez votre réponse :
   - **Choix unique** : une seule option ;
   - **Choix multiples** : plusieurs options possibles.
3. Cliquez sur **Voter**.

Tant que le sondage est ouvert, vous pouvez **Retirer mon vote** puis voter à nouveau.

## Voir les résultats

Selon le réglage du sondage, les résultats sont visibles tout de suite, après votre vote, ou seulement à sa fermeture. Le message sous le sondage vous le précise.

> **Bon à savoir** : dans un sondage **Anonyme**, personne ne voit qui a voté quoi.

> Si vous choisissez l'option **Autre**, le portail vous propose de décrire votre idée dans la **Boîte à suggestions**.

Le badge **Bientôt fermé** et la date **Jusqu'au** indiquent le temps qu'il reste pour voter.
