# Rôles et permissions

L'administrateur a tous les droits. Pour confier une partie de la gestion à d'autres, créez des **rôles** dans **Administration → Rôles**.

## Les permissions disponibles

| Permission | Ce qu'elle ouvre |
|---|---|
| **Gérer les ressources** | Ressources et leurs catégories |
| **Gérer les actualités** | Articles et création de tags |
| **Gérer les événements** | Événements de l'agenda |
| **Gérer les sondages** | Créer, clore et supprimer des sondages |
| **Modérer les commentaires** | Modération sur tout le site |
| **Gérer les sous-groupes** | Page « Mes groupes » |

Chaque permission a une **Portée** :

- **Tout le site** : la personne gère tout le module ;
- **Ses groupes** : seulement ce qui concerne ses groupes (et leurs sous-groupes).

## Créer un rôle

1. Ouvrez [Rôles](/admin/roles) et cliquez sur **Nouveau rôle**.
2. Donnez un **Nom** (ex. « Communication ») et une **Description**.
3. Cochez les **Permissions** et choisissez la **Portée** de chacune.
4. Cliquez sur **Enregistrer**.

## Attribuer un rôle

- **Gérer les membres** sur la carte du rôle : cherchez et ajoutez des personnes.
- Ou, dans la fiche d'un utilisateur, onglet **Rôle & groupes**, section **Rôles attribués**.

Une personne peut avoir plusieurs rôles : leurs permissions s'additionnent.

> **Bon à savoir** : pour limiter un rôle à certains groupes d'une personne, ouvrez sa fiche utilisateur et réglez **Groupes couverts par le rôle**.

Supprimer un rôle retire ses permissions à tous ses membres.
