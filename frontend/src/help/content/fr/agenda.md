# Agenda

L'[Agenda](/events) affiche les événements de l'organisation et les jours fériés. Vous voyez les événements publics et ceux destinés à vos groupes.

## Consulter les événements

1. Ouvrez **Agenda** dans le menu.
2. Choisissez l'**Affichage** : **Calendrier** ou **Liste**.
3. Cliquez sur une catégorie pour n'afficher que ses événements ; **Jours fériés** n'affiche que les jours fériés. Cliquez de nouveau pour revenir à tout.
4. Cliquez sur un événement pour voir sa date, son heure, son **Lieu** et ses **Liens externes** (visioconférence, inscription…).

## Repères

- **Toute la journée** : l'événement n'a pas d'heure précise.
- **Récurrent** : il se répète (chaque jour, semaine, mois ou année).
- **Passé** : il a déjà eu lieu.

## Compter les jours ouvrés

Le calculateur **Jours ouvrés**, sous l'agenda, compte les jours travaillés entre une **Date de début** et une **Date de fin**. Cliquez sur les **Jours de week-end** pour choisir vos jours de repos, et cochez **Exclure les jours fériés du calcul** si besoin.

> **Bon à savoir** : les **Événements à venir** apparaissent aussi sur votre page d'accueil. Vous pouvez commenter un événement depuis sa page.
