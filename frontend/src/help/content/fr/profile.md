# Profil et notifications

## Mettre à jour votre profil

1. Cliquez sur votre nom en bas du menu, puis sur **Mon Profil**.
2. Ajoutez une **Photo de profil** : **Téléverser une photo** (JPG, PNG, GIF ou WebP, 5 Mo maximum).
3. Complétez vos **Informations personnelles** (prénom, nom, téléphone, localisation) et **Informations professionnelles** (poste, département).
4. Cliquez sur **Enregistrer**.

Votre nom d'utilisateur ne change pas. Pour modifier votre e-mail, contactez un administrateur.

## Changer de mot de passe

1. Dans **Mon Profil**, cliquez sur **Changer le mot de passe**.
2. Saisissez le **Mot de passe actuel**, puis le nouveau deux fois (8 caractères minimum).

> Si vous vous connectez avec votre compte Microsoft, votre mot de passe se gère chez Microsoft, pas ici.

## Notifications

La **cloche**, en haut du menu, signale ce qui est nouveau pour vous. La page [Notifications](/notifications) permet de :

- n'afficher que les **Non lues** ;
- **Marquer comme lue** une notification, ou **Tout marquer comme lu** ;
- **Supprimer les lues** pour faire le ménage.
