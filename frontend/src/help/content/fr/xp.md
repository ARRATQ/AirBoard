# Points et badges

[My XP](/gamification) récompense votre participation : vous gagnez des points (XP), montez de niveau et débloquez des badges.

## Gagner des points

Vous gagnez des points en utilisant le portail, par exemple :

- vous connecter chaque jour ;
- lire un article, ouvrir une ressource ;
- voter à un sondage, commenter ;
- proposer ou soutenir une suggestion ;
- publier un article ou un événement, si votre rôle le permet.

Le nombre de points de chaque action est fixé par l'administrateur. **Activité Récente** montre ce que vous ont rapporté vos dernières actions.

## Suivre votre progression

- **Niveau** : la barre indique les points qui vous manquent pour le suivant.
- **Série** : nombre de jours de connexion d'affilée.
- **Badges** : filtrez **Tous**, **Débloqués** ou **Verrouillés** ; chaque badge dit comment l'obtenir.
- **Classement Général** : votre **rang** parmi les participants.

> **Bon à savoir** : la carte **Mon XP** de l'accueil résume tout cela ; **Détails** ouvre cette page.
