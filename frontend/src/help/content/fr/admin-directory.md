# Gérer le trombinoscope

La gestion du trombinoscope (**Administration → Trombinoscope**) décrit l'organisation : unités, postes et personnes. Trois onglets : **Structure**, **Personnes**, **Champs personnalisés**.

## 1. Construire la structure

1. Onglet **Structure** : **Nouvelle unité**. Indiquez le **Nom de l'unité**, un **Sigle**, une **Couleur** et l'**Unité parente** (vide = niveau racine).
2. **Ajouter une sous-unité** sous une unité existante pour descendre d'un niveau.
3. **Nouveau poste** dans une unité : **Intitulé du poste**. Cochez **Poste de responsable** pour le mettre en tête de l'unité.

## 2. Ajouter les personnes

1. Onglet **Personnes** : **Nouvelle personne**. Prénom, nom, e-mail, téléphone, photo.
2. **Compte Airboard lié** (facultatif) : reliez la fiche au compte de la personne.
3. Gardez **Fiche visible dans le trombinoscope** coché.

## 3. Affecter aux postes

Dans **Structure**, sur un **Poste vacant**, cliquez sur **Nommer** et choisissez la personne. Cochez **Intérim** si c'est temporaire. **Modifier l'affectation** et **Retirer du poste** sont sur chaque titulaire.

## Groupes liés aux unités

Le bouton **Groupe d'utilisateurs** d'une unité propose :

- **Créer les groupes depuis le trombinoscope** : un groupe par unité, pour cette unité seule ou avec toutes ses sous-unités, en gardant la hiérarchie ;
- **Lier un groupe existant** ;
- **Retirer le lien** : le groupe reste, les membres venus du trombinoscope en sortent.

Les personnes affectées à un poste de l'unité, dont la fiche est liée à un compte, en deviennent membres automatiquement. Un changement d'affectation met le groupe à jour. **Synchroniser les groupes** recalcule tout.

## Champs personnalisés

Onglet **Champs personnalisés** : **Nouveau champ** (bureau, matricule…). Choisissez le **Type**, s'il est **Obligatoire**, sa **Visibilité** (tous, ou **Gestionnaires** seulement) et s'il s'affiche sur la carte de l'annuaire.
