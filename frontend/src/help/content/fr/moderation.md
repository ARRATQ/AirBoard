# Modérer les commentaires

Votre rôle vous permet de modérer les commentaires de **tout le site**. La modération se fait depuis **Administration → Modération**.

## Traiter les commentaires en attente

1. Ouvrez [Modération](/admin/comments), onglet **En attente**.
2. Pour chaque commentaire, lisez le **Contenu** et l'**Élément commenté**.
3. Choisissez :
   - **Approuver** : le commentaire devient visible ;
   - **Signaler** : il est marqué **Signalé** pour être revu ;
   - **Supprimer** : il disparaît définitivement.

## Agir directement sur une page

Sur un article, un événement ou une suggestion, vous pouvez **Modifier** ou **Supprimer** n'importe quel commentaire, pas seulement les vôtres.

## Régler les commentaires

L'onglet **Paramètres** permet de :

- **Activer les commentaires**, puis les autoriser ou non sur les actualités, les ressources et les événements ;
- rendre la **Modération obligatoire** : chaque nouveau commentaire attend alors votre validation ;
- fixer la **Longueur maximale des commentaires**.

Cliquez sur **Enregistrer les paramètres** pour appliquer.
