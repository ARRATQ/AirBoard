# Groupes

Les groupes décident **qui voit quoi** : ressources, actualités, événements, sondages ciblés. Ils se gèrent depuis **Administration → Groupes**.

## Créer un groupe

1. Ouvrez [Groupes](/admin/groups) et cliquez sur **Nouveau groupe**.
2. Onglet **Général** : **Nom du groupe**, **Couleur d'identification**, **Description**, et **Groupe parent** si c'est un sous-groupe.
3. Onglet **Accès** : cochez les **catégories de ressources** que ce groupe peut voir.
4. Cliquez sur **Créer le groupe**.

Les membres s'ajoutent depuis la fiche de chaque utilisateur (page Utilisateurs) ; l'onglet **Membres** les affiche.

## Sous-groupes

Un groupe placé sous un **Groupe parent** est un sous-groupe :

- ses membres voient aussi ce qui est destiné au groupe parent ;
- un rôle limité au groupe parent couvre aussi le sous-groupe.

La liste affiche les groupes en arbre, avec « Sous-groupe de : ».

## Groupes liés au trombinoscope

Un groupe marqué **Trombinoscope : …** suit une entité de l'organisation : les personnes affectées à cette entité en sont membres automatiquement. Le lien se règle dans la gestion du trombinoscope (guide « Gérer le trombinoscope »).

## Groupe par défaut

Le groupe par défaut réunit tout le monde. Il se choisit dans **Réglages → Accès et authentification**.

> **Bon à savoir** : pour confier l'organisation de sous-groupes à quelqu'un sans lui donner tous les droits, donnez-lui un rôle avec la permission **Gérer les sous-groupes**.

Supprimer un groupe retire toutes ses appartenances ; c'est irréversible.
