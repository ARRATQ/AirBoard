# الإعدادات والمتابعة

## نظرة عامة

تلخّص [نظرة عامة](/admin) النشاط: **أرقام رئيسية** والعناصر **بانتظار المعالجة**.

## الإعدادات

تخصّص [الإعدادات](/admin/settings) البوابة:

- **عام**: اسم التطبيق وأيقونته، عناوين الصفحة الرئيسية ورسائلها، عدد المقالات في موجز الأخبار، صورة شريط الصفحة الرئيسية (الوضع الفاتح والداكن)؛
- **الرسائل الديناميكية**: الرسائل المتتابعة في شريط الصفحة الرئيسية؛
- **الوصول والمصادقة**: فتح التسجيل أو لا، واختيار **المجموعة الافتراضية** للحسابات الجديدة؛
- **المظهر**: لوحات ألوان البوابة؛
- **منطقة الخطر**: إعادة تعيين قاعدة البيانات. لا تستخدمها إلا إذا كنت تعرف ما تفعل: فهي تمحو البيانات.

## تسجيل الدخول OAuth

تضبط صفحة [تسجيل الدخول OAuth](/admin/oauth) الاتصال عبر Microsoft أو Google:

1. انقر على **تهيئة** للمزوّد.
2. الصق **معرّف العميل** و**السر الخاص بالعميل** من وحدة تحكم المزوّد.
3. انسخ **عنوان إعادة التوجيه** إلى وحدة التحكم تلك.
4. فعّل **تفعيل مزوّد OAuth هذا**: يظهر زره في صفحة تسجيل الدخول.

## البريد الإلكتروني

تضبط صفحة [البريد الإلكتروني](/admin/email) إرسال الإشعارات: خادم الإرسال، **قوالب البريد الإلكتروني** و**سجل الإرسال**.

## الإحصاءات والتقارير

- [الإحصاءات](/admin/analytics): النقرات على الموارد، المستخدمون الفريدون، ساعات الذروة، الموارد الأكثر استخدامًا. **تصدير البيانات** ينزّل الأرقام.
- [التقارير](/admin/reports): النشاط حسب الدور والمجموعة والمستخدم (قراءات، أصوات، منشورات، أبرز المساهمين).

## روبوتات الدردشة

تضيف [روبوتات الدردشة](/admin/chatbots) مساعدين إلى البوابة: **روبوت جديد**، ثم **الاسم** و**رابط Webhook لـ n8n**. **تفعيل** / **تعطيل** يُظهرها للمستخدمين أو يخفيها.

> **معلومة مفيدة**: لا تلصق أبدًا سرًّا (كلمة مرور، سر العميل) في غير حقله المخصص.
