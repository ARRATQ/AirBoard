# Managing the directory

Directory management (**Administration → Who's Who**) describes the organisation: units, positions and people. Three tabs: **Structure**, **People**, **Custom fields**.

## 1. Build the structure

1. **Structure** tab: **New unit**. Enter the **Unit name**, an **Acronym**, a **Colour** and the **Parent unit** (empty = top level).
2. **Add sub-unit** under an existing unit to go one level down.
3. **New position** in a unit: **Position title**. Tick **Head position** to put it at the top of the unit.

## 2. Add people

1. **People** tab: **New person**. First name, last name, email, phone, photo.
2. **Linked Airboard account** (optional): link the card to the person's account.
3. Keep **Profile visible in the directory** ticked.

## 3. Assign people to positions

In **Structure**, on a **Vacant position**, click **Assign** and choose the person. Tick **Acting** if it is temporary. **Edit assignment** and **Remove from position** are on each holder.

## Groups linked to units

A unit's **User group** button offers:

- **Create groups from the directory**: one group for this unit and one for each of its sub-units, named after them and with the same hierarchy. Sub-units are always included: for a single sub-unit, start from that sub-unit. An existing group with the same name is linked instead of being created again;
- **Link an existing group**: for this unit only; a group can be linked to one unit only;
- **Remove the link**: the group stays, members who came from the directory leave it.

People assigned to a position in the unit, whose card is linked to an account, become members automatically. A change of assignment updates the group. **Sync groups** recalculates everything.

## Custom fields

**Custom fields** tab: **New field** (office, staff number…). Choose the **Type**, whether it is **Required**, its **Visibility** (everyone, or **Managers** only) and whether it shows on the directory card.
